# Calundike Exports - customer website (design concept)

A clickable design concept of the planned Calundike Exports customer website, for stakeholder review. It is not a
live shop: nothing typed into it is sent anywhere, and prices, sizes and contact details are placeholders.

Pages: Home (`index.html`), Catalogue, Product page (photos, 360° view, 3D), Quote list -> request a quotation,
and My account (sign in, first-time activation, a sample signed-in account).

The quote list is kept in the visitor's own browser so it carries across pages.

Photos are free stand-ins from Unsplash (see `assets/img/PHOTO-CREDITS.txt`) until the Calundike team's own product
photos replace them. The logo is the Calundike Exports logo, unchanged.

Static HTML, CSS and Vue 3 (from a CDN); served with GitHub Pages.
